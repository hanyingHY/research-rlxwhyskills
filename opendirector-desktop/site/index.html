和网页版一模一样的创作能力

桌面版加载的是同一套界面与业务逻辑，不是精简版，也不是另一套实现。

  • 完整画布：文本、图像、视频、音频、主体与时间线节点，拖拽导入，自动保存。
  • 对话助手：生成素材、整理画布、编排时间线，输入 @ 引用现有素材。
  • 时间线与导出：本机渲染 MP4，支持素材包与画布导出。
  • 模型连接：对话 / 图像 / 视频 / 语音服务，密钥留在本机。
  • 同一份数据：与命令行共享 ~/.opendirector，随时切换工作方式。
  • 自带运行时：Python、OpenCode Agent 与 FFmpeg 随应用安装，不需要自己配环境。
  • 自动更新：macOS / Windows / Linux AppImage 内置更新检查，更新不打断正在进行的任务。
  • 中英双语：界面、引导、帮助中心都跟随系统语言，可随时切换。

渐进式指引，不打扰

第一次打开时有一次欢迎页与 3 分钟导览；之后只在需要的时候出现一张小提示。

首次启动

欢迎页说明数据放在哪里，并提供「开始导览」或「直接进入」，选择会被记住。

按需提示

没有配置模型、第一次打开时间线、打开助手时才出现对应提示，每条都能「不再显示」。

随时回看

按 F1 打开桌面版指引，按 ? 查看画布快捷键；帮助里可以重播导览、重置提示、打开日志。

安装

从 GitHub 发布页下载与你的系统、架构对应的安装包。

Windows

运行 OpenDirector-<版本>-win-x64.exe，选择安装位置。SmartScreen 提示时选择「更多信息 → 仍要运行」。

macOS

打开 DMG 把 OpenDirector 拖进「应用程序」。首次启动若被拦截，到「系统设置 → 隐私与安全性」点「仍要打开」。

Linux

chmod +x OpenDirector-*.AppImage && ./OpenDirector-*.AppImage；或 sudo apt install ./OpenDirector-*.deb。

从源码运行：cd opendirector-desktop && npm ci && npm start。需要 Node 22+、Python 3.12 与 FFmpeg。

常见问题

为什么安装包这么大？

安装包内含 Python 运行时、OpenDirector 依赖、Agent 二进制与 FFmpeg，安装后约 500–700 MB。这是「不需要用户装环境」的代价。

会自动上传我的项目吗？

不会。项目、素材与模型密钥都保存在本机；只有你配置的模型服务会收到生成请求。日志不记录密钥与请求正文。

项目存在哪里？

默认是主目录下的 .opendirector，与命令行版本共用。可以在「文件 → 更改项目数据目录」里修改，重启后生效。

为什么 macOS / Windows 提示未签名？

当前发布流程默认不签名。未签名安装包可以运行，但系统会提示一次；同时自动更新需要签名校验，未签名版本请手动下载新安装包。

桌面版和网页版会有功能差异吗？

业务功能一致：桌面版加载同一份 Web 界面与 API。差异只在桌面外壳：原生窗口、菜单、更新、数据目录与引导层。
